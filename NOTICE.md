# Attribution And Source

This is an unofficial deployment distribution of Joplin Web, derived from Joplin Mobile. Joplin code is copyright Laurent Cozic and contributors and licensed under AGPL-3.0-or-later, unless an upstream component specifies another license. The extracted bundles retain their upstream license notices. This repository does not contain the Joplin desktop client, native Android/iOS build projects, or Joplin Server database implementation.

The upstream application bundle has reproducible, AST-checked hooks for the self-hosted card view, notebook emoji editor, and Tags screen creation control, plus tag queries that include unassigned tags; service worker and other worker bundles remain unchanged. Web document titles, manifest metadata, standalone application icons, and `environment.js` are adapted. Development mode stays disabled for this production build, including on localhost. The added hosting/proxy and UI code is licensed under AGPL-3.0-or-later. `upstream-assets.json` records the extraction source, original/resulting content hashes, and local UI asset hashes. Upstream corresponding application source is available at https://github.com/laurent22/joplin; build instructions are at https://github.com/laurent22/joplin/blob/dev/readme/dev/BUILD.md#web. This is a customized distribution of the upstream browser build, not an independently rebuilt source fork; the transformation and UI source are included in this repository.

Joplin is a trademark of JOPLIN SAS. The original Joplin logos and app icons have a separate restricted license and are not granted by the AGPL. This distribution replaces its standalone web app icons with an independently created document icon. Other third-party notices are retained alongside their bundled JavaScript.

See `SOURCES.md` for the immutable corresponding source of the included browser build and source download links. See `VERIFICATION.md` for tested behavior and remaining deployment checks.

The local metadata controls bundle `@joeattardi/emoji-button` 4.6.4, the MIT-licensed picker also used by Joplin Desktop. Its source is at https://github.com/joeattardi/emoji-button/tree/v4.6.4. Picker and dependency notices are included in `web/emoji-picker.LICENSE.txt`; versions are pinned by `package-lock.json`. The native emoji rendering mode is used, not remotely hosted Twemoji images.
